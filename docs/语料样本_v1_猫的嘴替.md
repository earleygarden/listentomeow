# 听喵说 · 猫的嘴替 —— 语料样本 v1

> 给鳄梨导演看语气用。**不是按场景让用户选，而是系统自己从「此刻几点 + 这段声的形状」里取。**
> 用户只做一个动作：传一段猫叫。别的一律不问。

---

## 一、触发信号（全部自动，零输入）

| 信号 | 来源 | 举例 |
|---|---|---|
| 此刻几点 | 服务器时间 | 凌晨 23:47 / 早上 7:20 |
| 星期几 | 服务器时间 | 周一 / 周五晚 |
| 这段多长 | 音频时长 | 0.5s 一声 / 6s 拖长 |
| 多大声 | 峰值/RMS | 贴着话筒小声 / 隔屋大吼 |
| 叫了几次 | 能量包络峰计数 | 就一声 / 连着叫了四声 |
| 今天第几次玩 | localStorage | 第三次 |
| 粗情绪 | 现有模型（B/F/I + 拿不准） | 当语气开关用，不当结论 |

**关键取舍**：不说"我听懂了你在想什么"，只说"此刻 + 这段声"。时间是真的，声音的形状也是真的——"准"来自这里，不来自假装情绪识别很准。

## 二、样句（先看语气，数量不做样板）

### 深夜 22:00–03:00

- 这么晚还没睡？行吧，我陪你熬。
- 灯关一半了，你先躺下。我在门口看着。
- 几点了？你再不睡，明天别喊困。（毒舌）
- 又是不睡。你是不是也觉得今天没过完？（毒舌）
- 我今天一整天都没见着你。（小声＋长音）
- 喂。喂。喂。（连着叫）
- 别忙了。今天已经够长了。

### 清晨 05:00–09:00

- 醒了？那开工吧，我也饿了。
- 今天不用表现很好。活着回来就行。
- 周一。我建议你今天装死。（毒舌，仅周一）
- 让我再睡会儿…（长音）
- 你今天起得比昨天早。行，有进步。（毒舌）

### 白天 09:00–18:00

- 你人呢？
- 我在窗台上。太阳很好，你那边呢？
- 上班的时候想我，是没用的。（毒舌）
- 我睡了三觉了。你还没回。（连叫）

### 傍晚 18:00–22:00（回家时段）

- 你回来了。饭我吃过了，你那份我给你看着呢。
- 六点四十。你今天又晚了四十分钟。（毒舌）
- 门口！门口！门口！（连着叫＋大声）
- 别急着做饭。先坐一会儿。

### 周五晚 / 周末

- 明天不用早起。我们可以一起赖着。
- 这周到这儿了。过来，头给我摸一下。

### 只按"声音的形状"（任何时段都能用）

- 就一声。有事说事。（短促一声）
- ……我好无聊。（拖长音）
- 你别走。（连着叫）
- 我在这儿，你听见了吗。（小声）

### 连续使用（今天第 N 次）

- 你今天找我第三次了。是有事吧？
- 又来。行，我每次都理你。（毒舌）
- 你这么频繁地找我，是不是今天不太好过？

### 拿不准时（把它当素材，不当缺陷）

- 这段我没听清。但你要是想让人陪，我在这儿。
- 它在说话，只是我听不懂。你先说说你怎么了？
- 它欲言又止。你也一样吧？（毒舌）

## 三、语料库骨架（不是 500 条励志句，是矩阵）

```
时间档（深夜/清晨/白天/傍晚/周一周五特殊）  ×
声音形状（短促一声/拖长/连叫/小声/大吼）    ×
猫格（小奶猫/调皮小子/傲娇小姐/直爽大哥/温柔奶奶/沉稳大爷） ×
语气轨道（治愈承接 / 毒舌好笑）
```

按这个骨架，**12 个时间×形状组合 × 6 猫格 × 2 语气 ≈ 144 条**就能撑起产品；
每条都要有落点，宁可少而准，不堆泛励志句。

---

## 四、写句子的三条硬规矩（你自己审稿时也用得上）

1. **承接，不打气。** 不写"加油""明天会更好"。写"先躺下""头给我摸一下"。
2. **不复述主人的状态。** 不写"你很难过吧"。人怕被断言，不怕被接住。
3. **必须有一个具体的东西。** 时间（六点四十）、动作（把碗洗了）、身体（头、手、门口）。
   越具体越像真的，越抽象越像模板。

---

## 五、待你定的只有两件（都不用增加用户操作）

1. **首页默认哪条轨道**：治愈承接 / 毒舌好笑 / 随机混（我倾向默认治愈，结果页给一个"换句更狠的"按钮）。
2. **要不要「换一个」按钮**（同时间同形状同猫格里轮换，不跳到别的语境）——零输入成本，还能让语料库显得无穷。
